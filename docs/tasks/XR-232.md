# XR-232: Файлы: индикатор pull-to-refresh выезжает при входе без жеста

## Корень

Вход на вкладку «Файлы» дёргает `refreshHub` из `LaunchedEffect`, а индикатор
жеста в `ShareListView` привязан к общему флагу `loadingHub`, поэтому спиннер
обновления выезжает сам, без потягивания. Та же связка в `ExplorerView`:
открытие шары поднимает `manifestLoading`, и жестовый индикатор дублирует
центральный спиннер первого открытия.

## Починка

Как уже сделано в `RulesScreen`: индикатор жеста вешается на локальный флаг,
который взводят только ручные действия (потягивание и кнопка «Обновить» в
шапке) и который сбрасывается по окончании загрузки. Фоновые обновления
(вход на вкладку, открытие шары, офлайн-ретрай) индикатор жеста не трогают.

## Сценарий проверки (пользовательский)

1. Открыть приложение и перейти на вкладку «Файлы». Ожидание: список шар
   появляется без выезжающего сверху спиннера pull-to-refresh (до починки он
   выезжал при каждом входе).
2. Потянуть список шар вниз. Ожидание: спиннер выезжает, крутится, пока идёт
   обновление, и прячется.
3. Нажать кнопку «Обновить» в шапке. Ожидание: тот же спиннер показывается на
   время обновления.
4. Открыть шару. Ожидание: жестового спиннера сверху нет (при пустом кэше
   остаётся центральный спиннер первой загрузки); потягивание списка вниз
   внутри шары работает как в п. 2.
