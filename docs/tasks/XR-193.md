# XR-193: Публичный GET /api/v1/shares без аутентификации перечисляет адреса всех агентов флота (addr, LAN-addrs, порт, pubkey, имя): скрыть индекс за грант/скоуп инвайта

## Что происходит

`GET /api/v1/shares` без аутентификации отдаёт индекс всех агентов флота:
внешние адреса, LAN-адреса, порты, публичные ключи и имена. Любой, кто знает
адрес хаба, получает карту инфраструктуры.

## Чего хотим

Индекс скрыт за аутентификацией: ручка требует грант или скоуп инвайта,
анонимный запрос отвергается. Задача из состава цели XR-286, конвейер идёт
по её файлу.

## DoD

- Анонимный `GET /api/v1/shares` отвечает 401; содержательные клиенты
  (грант/скоуп инвайта) продолжают читать индекс, штатный обмен шаблонами
  не ломается.
- Поведение покрыто тестом стенда xr-hub.
- Сквозная проверка после выката: `curl -s -o /dev/null -w '%{http_code}' https://$HUB/api/v1/shares`
  без токена печатает `401`.

## Сценарий проверки

Агентский, после выката (адрес хаба из `.devkit/deploy.local`):

1. `curl -s -o /dev/null -w '%{http_code}' https://$HUB/api/v1/shares` без
   токена печатает `401`.
2. Грант берётся из admin API: `POST /api/v1/admin/shares/{id}/token` с сессией
   админки (логин `POST /api/v1/auth/login`, доступ из local-docs). Годится и живой
   инвайт из `GET /api/v1/admin/invites`.
3. `curl -s -o /dev/null -w '%{http_code}' -H "Authorization: Bearer <грант
   или инвайт>" https://$HUB/api/v1/shares` печатает `200` и отдаёт индекс.
