# XR-290: Роутерный выкат живёт мимо deploy.local, merge его не зовёт

записан 2026-09-04
приоритет: низкий

## Черновик

### Ситуация

Ключ deploy в .devkit/deploy.local катит xr-server на VPS, а правки xr-client
раскладывает отдельный .devkit/deploy-router.sh, который shipctl merge не
знает. Задача, меняющая только клиент роутера (XR-285 ровно такая), проходит
слияние с выкатом, но на роутеры не доезжает, и раскатку делают руками. Нужен
второй ключ выката (по образцу deploy_xr_hub) и правило, по которому задача
называет свой объект выката, иначе «слито и выкачено» продолжит означать
разное для разных задач.
