# XR-288: DoT-апстрим рвёт соединение по простою, лишний хендшейк на запросе

записан 2026-09-04
приоритет: средний

## Черновик

### Ситуация

После выката XR-285 на обоих роутерах в logread два-три раза в минуту под
нагрузкой идёт «dns: upstream closed the connection, will reconnect on next
query». Резолв не страдает, переподключение отрабатывает, но каждый обрыв
стоит нового TLS-хендшейка поверх туннеля, то есть лишнего RTT до VPS на
первом же запросе после паузы. Похоже на idle-таймаут публичного резолвера
(RFC 7858 разрешает закрывать простаивающее соединение). Лечится keepalive к
апстриму либо предупредительным переподключением по своему таймеру, чтобы
хендшейк не попадал на живой запрос. Из проверки XR-285.
