# XR-280: Стоп туннеля из шторки уведомления (ACTION_STOP -> XrVpnService.stopFromUi) идёт мимо viewModel.disconnect() и не отменяет reconnectJob: стоп, попавший в окно ~0.6с переключения сервера (Stopping/Idle), позволит висящему реконнекту поднять туннель обратно вопреки действию пользователя. Найдено на проверке XR-088; окно для пользователя практически неуловимо, потому мелочь, но путь без отмены существует. Лечится тем же reconnectJob?.cancel() на пути ACTION_STOP

записан 2026-08-12

## Черновик

Стоп туннеля из шторки уведомления (ACTION_STOP -> XrVpnService.stopFromUi) идёт мимо viewModel.disconnect() и не отменяет reconnectJob: стоп, попавший в окно ~0.6с переключения сервера (Stopping/Idle), позволит висящему реконнекту поднять туннель обратно вопреки действию пользователя. Найдено на проверке XR-088; окно для пользователя практически неуловимо, потому мелочь, но путь без отмены существует. Лечится тем же reconnectJob?.cancel() на пути ACTION_STOP
