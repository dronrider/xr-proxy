# XR-268: check-browser-entry.py считает Sec-WebSocket-Accept по неверному магическому GUID (258EAFA5-E914-47DA-95CA-5AB0DC85B11F вместо 258EAFA5-E914-47DA-95CA-C5AB0DC85B11 из RFC 6455): ошибка симметрична, тот же GUID стоит в эхо-сервисе скрипта, поэтому на стенде проверка зелёная, а против настоящего сервера рукопожатие объявляется несошедшимся.
