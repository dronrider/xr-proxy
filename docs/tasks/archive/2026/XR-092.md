# XR-092: Мультиязычность приложения (i18n): вынести строки UI в ресурсы (strings.xml), локали ru/en, выбор по системной. Сейчас строки захардкожены в Kotlin вперемешку на двух языках. iOS: strings.xml не переносится, на iOS свой формат локализации

Прогон 2026-08-12 после слияния. Агентская часть в main зелёная (42 JVM-теста,
компиляция без warnings, APK собирается, греп кириллицы находит только журнал
диагностики). Экранная часть на эмуляторе: главный экран, Серверы, Правила с
диалогом, Файлы, Журнал и уведомление сервиса сняты дампами в обеих локалях,
en-экраны англоязычные, ru-экраны русские, формулировки из ресурсов, наложений
нет. Предсуществующие отступления (русские строки движка в en-UI через
Raw-путь, английские остатки дефолтной таблицы в журнале, debug-панели и
статистике) заведены черновиками XR-281 и XR-282, к рамкам задачи не
относятся.

## Ход работы

- Исполнение: субагент opus/medium по вердикту pick (квота: week_all 26%, week_max 31%, снимок 0м назад, сдвига нет), 2026-08-12.
- Ревью: субагент sonnet/high по вердикту pick (квота: week_all 26%, week_max 31%, снимок 27м назад, сдвига нет), 2026-08-12.

## Решение

Строки UI переехали в таблицу строк: `app/src/main/res/values/strings.xml` это
русский по умолчанию, `values-en/strings.xml` перевод. Всего 455 ключей, из них
два `plurals` (файлы в папке, резервные адреса сервера). Язык выбирает система
по своей локали, переключателя внутри приложения нет. Русский текст канон и
перенесён буква в букву, английский идёт переводом; согласованные формулировки
(«в очереди», «Очередь импорта заполнена, попробуй позже», «Профиль добавлен,
активный сервер прежний», «Переключаю сервер», тексты ошибок шары) не тронуты.

Ключи именуются по экрану: `vpn_`, `main_`, `logs_`, `debug_`, `stats_`,
`health_` (главный экран и общие компоненты), `files_` и `share_` (проводник и
шара), `servers_`, `invite_`, `trusted_`, `journal_`, `update_` (серверы,
онбординг, доверенные сети, обновление), `rules_` (правила маршрутизации),
`notif_`, `service_`, `data_` (уведомления, сервис, слой данных). Подстановка
только позиционными плейсхолдерами (`%1$s`, `%2$d`), склейки из кусков
разобраны в один ресурс. В Compose строка берётся `stringResource`, в сервисе и
классах данных `getString` по `Context`, во вьюмоделях через `getApplication()`.

Чистая Kotlin-логика без Android SDK покрыта JVM-юнитами, и текстов она теперь
не носит вовсе: возвращает ключ, а строку по ключу собирает слой Compose. Так
разделение переносится на iOS, где ресурсы устроены иначе, а словарь ключей тот
же.

- `ShareErrorText.kt`: `humanShareError`/`humanImportError` стали
  `shareErrorOf`/`importErrorOf` и возвращают `ShareErrorText` с двумя
  вариантами: `Known(kind, arg)` со своей формулировкой (`ShareErrorKind`,
  14 значений, `arg` несёт код ответа) и `Raw(text)` для текста, который движок
  прислал готовым. Ресурс подбирает `renderShareError` в `FilesScreen.kt`, там
  `when` по enum, полноту проверяет компилятор. `isTransientAgentErrorCategory`
  не тронут.
- `SyncProgress.kt`: `SyncIndicator.counter` («3 из 5») разложился на `current`
  и `total`, подпись собирает экран ресурсом `files_sync_counter`.
- `Share.kt`: заголовок группы проводника стал `GroupTitle` -
  `Known(GroupKind)` для своих подписей и `Text(text)` для того, что взять
  больше неоткуда (имя источника от агента, отформатированный месяц). Тайбрейк
  порядка групп переехал с подписи на ключ группы, порядок прежний.
  `monthLabel` форматируется по `Locale.getDefault()`, иначе английское
  приложение подписывало бы группы русскими месяцами.
- `ServerProfile.displaySubtitle`, `StorageAccess.label` и
  `ServerRepository.generateName` стали принимать `Context`.

Тесты перестроены под новые типы и проверяют то же самое: `ShareErrorTextTest`
сравнивает варианты вместо русских строк (все разборы категорий на месте),
`SyncProgressTest` сравнивает числа вместо подписи, `ShareGroupingTest`
рендерит свои заголовки именем ключа. Всего 42 JVM-теста, зелёные.

В коде намеренно остались 30 строковых литералов с кириллицей: это записи
журнала диагностики (`nativeJournalLog` в `XrVpnService`, `RestrictionProbe`,
`VpnStopReason`) и `Log.w`. Журнал не локализуется, он обязан совпадать по
языку с движком на Rust, который эти же записи и пишет. Там же остались
технические метки, которые на экран не выходят (`VpnUiState.state`, коды ошибок
`UpdateManager` и `ShareRepository`, синтаксис TOML в `TomlBuilder`, метки
источника профиля `Invite`/`Manual`, названия модификаторов из `server.toml`).

Тексты, где исходник нарушал правила символов, переписаны: длинное тире
перестроено в живую фразу, одиночное многоточие заменено тремя точками, стрелки
вверх и вниз в статусе уведомления стали словами «отдано» и «получено», знак
предупреждения убран (роль маркера остаётся за цветом).

## Сценарий проверки

Агентский:

- `cd xr-android && ./gradlew :app:compileDebugKotlin :app:testDebugUnitTest` -
  зелено, 42 теста.
- `cd xr-android && ./build.sh` - APK собирается, это главный смок по ресурсам:
  недостающий или битый ключ валит `processDebugResources`.
- Полнота: греп по строковым литералам с кириллицей во всех `.kt` под
  `app/src/main/java` (комментарии и KDoc отбрасываются) даёт только записи
  журнала и `Log.*`, перечисленные в решении.
- Наборы ключей `values/strings.xml` и `values-en/strings.xml` совпадают один в
  один, кроме `app_name`; дублей имён нет.

Пользовательский, экранный:

- Переключить язык системы на английский (Settings, Languages, English) и
  пройтись по экранам: главный с тумблером и статусами, серверы и переключатель,
  правила, проводник с очередью синка и ошибками, онбординг по инвайту,
  доверенные сети, журнал, баннер обновления, шторка уведомления с туннелем.
  Тексты английские, обрезанных и налезающих подписей нет.
- Вернуть русский: те же экраны по-русски, формулировки прежние.
