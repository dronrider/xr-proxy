# XR-239: Хаб отдаёт админку и остальные ответы без защитных заголовков: ни CSP, ни X-Content-Type-Options, ни Referrer-Policy (найдено попутно с XR-192, там закрыта только страница инвайта)

## Что происходит

XR-192 закрыл защитными заголовками только страницу инвайта. Админка
и остальные ответы хаба уходят без CSP, X-Content-Type-Options
и Referrer-Policy.

## Чего хотим

Защитные заголовки стоят на всех ответах хаба, включая статику админки,
одной точкой, а не по одному хендлеру. Задача из состава цели XR-286,
конвейер идёт по её файлу.

## DoD

- Ответы хаба несут CSP, X-Content-Type-Options и Referrer-Policy, включая
  статику admin UI; страница инвайта не теряет свои заголовки из XR-192.
- Наличие заголовков покрыто тестом стенда xr-hub.
- Сквозная проверка после выката: `curl -sI https://$HUB/` содержит строку
  `Content-Security-Policy`.

## Тесты

- Исключение: тесты (тесты в ветке есть, это два новых теста в модуле
  `#[cfg(test)]` файла `xr-hub/src/api/mod.rs`, но ворот слияния узнаёт
  тестовые файлы по суффиксам `_test.go/.py/.sh`, а Rust-овские модульные
  тесты в тех же файлах не видит).

## Ранг

0+3+1+0+1 = 5, P3.

- Серьёзность 0 (Minor): без заголовков продуктом пользуются и не замечают
  их отсутствия, прямого ущерба пользователю нет.
- Ценность 3: укрепление на будущее, MIME-sniffing и кликджекинг админки
  закрываются, разошедшийся скрипт CSP держит в рамках своего origin.
- Неопределённость 1: точка встраивания названа в постановке, оставалась
  одна развилка со значением CSP под потребности админки.
- Поправка на баг 0: новая работа, заголовков на остальных ответах никогда
  не стояло.
- Рычаг 1: одна точка заголовков пригодится следующим задачам укрепления
  хаба, чужую работу задача не разблокирует.

## Ревью

Прогон glm-5.3/high 2026-08-29 по диффу против main, замечаний нет.

Слой стоит в единственной точке. Хаб собирает один роутер в `api::router`
и монтирует его единственным слушателем, слой после `fallback_service`
накрывает и маршруты, и статику админки. `if_not_present` оставляет странице
инвайта её единственный nonce-CSP, тест ловит и задвоение, и подмену строгой
политики общей. Значение CSP сверено с исходниками фронта, стенд гоняется на
заглушке без сборки UI. QR рисуется `QRCode.toDataURL` в `data:`. Тема
PrimeVue вставляется тегами стилей в рантайме, в SharesList.vue есть
инлайновый атрибут стиля, оба покрываются `unsafe-inline` в style-src.
Инлайн-скриптов и внешних ресурсов в сборке нет. Раздатка `/share` и заглушка
503 отдают не HTML, CSP на них не действует.

regcheck по inline-региону `api/mod.rs` прогнан ревью повторно. Тесты краснеют
на main и проходят на ветке, пакет xr-hub зелёный целиком без предупреждений.
Раздел ARCHITECTURE.md лёг рядом с XR-192, формула ранга у файла и строки
доски сходится, lint доски чист.
