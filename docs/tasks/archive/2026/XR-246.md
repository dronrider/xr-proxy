# XR-246: Тесты xr-hub не собираются в свежем worktree: embed требует гитигнорнутый admin-ui/dist, и первый shipctl merge по любой задаче падает на несборке. Собирать фронт автоматом либо отдавать заглушку, когда сборки нет

Строка заведена до того, как чинить взялись в XR-238, и осталась висеть после
её закрытия. Починка приехала коммитом 712b4af: `xr-hub/build.rs` спрашивает
`ui_dist::pick()`, и в отладочной сборке без `admin-ui/dist` вшивается
заглушка вместо отказа компилятора. Релизная сборка по-прежнему требует npm.

фронта), `cargo test -p xr-hub`:
