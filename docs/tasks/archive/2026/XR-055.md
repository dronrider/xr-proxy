# XR-055: кривая компоновка карточки шары в «Моих шарах»

Название втискивается в узкую колонку и обрезается («Антон Назаров - О...»),
хотя карточка уже трёхстрочная и место под имя есть.

## Причина (регрессия XR-043)

Один Row с ведущей иконкой + Column(weight 1f) + трейлинг-кластер из трёх
контролов (иконка «папка хранения» + тумблер синка + корзина); кластер ~150dp
плюс ведущая иконка ужимают колонку имени до ~110dp.

## Что сделать

Дать имени полную ширину без роста высоты блока: либо вынести заголовок в
отдельную верхнюю строку на всю ширину, а метаданные (выбрано/папка) + контролы
под ней; либо убрать третью иконку из кластера, сделав строку «Папка: ...»
тапабельной для смены папки (заголовку больше места).

Смежно с XR-044 (та же карточка/экран).

Код:
[ui/files/FilesScreen.kt:273](../../xr-android/app/src/main/java/com/xrproxy/app/ui/files/FilesScreen.kt#L273)

## Что сделано (первый заход, проверку не прошёл)

Выбран второй вариант: иконка «папка хранения» удалена из трейлинг-кластера,
смена папки тапом по строке «Папка: ...». Владелец забраковал («работа плохо
проделана») и указал целевые макеты в Claude Design (проект «Мобильное
приложение шар», Экран Шары): вариант 2a в комбинации с формой 1d.

## Что сделано (переделка по макетам 2a + 1d)

Карточка по 2a: тонированная плитка с папкой, имя одной строкой во всю ширину
с эллипсисом в середине (начало и хвост различимы), под ним строка статуса
«точка + Синхронизируется/выключена + выбрано: N». Все контролы ушли с
карточки, справа одна кнопка с тремя точками, тап по карточке только открывает
шару. Кнопка открывает bottom sheet по 1d: шапка с именем и статусом, «Открыть
шару», тумблер «Синхронизация», «Папка на устройстве» с текущим путём (ведёт в
прежний диалог), красное «Удалить шару». Удаление подтверждается undo-снекбаром
(«Отменить» возвращает конфиг как был, локальные файлы удаление не трогает).
Отступление от текстов макета: счётчик оставлен «выбрано: N» вместо «N файлов»,
в выборе бывают и папки. Ради MiddleEllipsis поднят Compose BOM до 2025.06.00 и
compileSdk до 35 (это же разблокирует XR-176 для проводника).

## Сценарий проверки (пользовательский)

1. Открыть «Файлы» -> «Мои шары» на шаре с длинным именем.
2. Карточка как в макете 2a: имя одной строкой с многоточием в середине
   (видны начало и конец), ниже точка-индикатор и статус синка, справа только
   кнопка с тремя точками. Ничего не бежит и не обрезается на «...О...».
3. Кнопка с тремя точками открывает лист как в 1d: «Открыть шару»,
   тумблер «Синхронизация», «Папка на устройстве» с текущим путём,
   красное «Удалить шару».
4. «Папка на устройстве» ведёт в прежний диалог смены папки; тумблер
   переключает синк, состояние видно и на карточке.
5. «Удалить шару» убирает карточку и показывает снекбар с «Отменить»;
   отмена возвращает шару со всеми настройками.
6. Тап по самой карточке открывает шару, как раньше.

## Ревью

- второе удаление при висящем снекбаре вставало в очередь showSnackbar, отклик задерживался на десять секунд: исправлено, текущий снекбар вытесняется перед показом нового
- restoreShare не дёргал syncNow, докачка после отмены удаления ждала периодического слота WorkManager: исправлено, включённый синк продолжает сразу, как в setSyncEnabled
- кнопки листа закрывали ModalBottomSheet без анимации hide, в отличие от свайпа и скрима: исправлено, dismissThen прячет лист через sheetState.hide и действует по завершении
- AGP 8.5 варнит на compileSdk 35 при каждой сборке: исправлено, android.suppressUnsupportedCompileSdk=35 в gradle.properties до подъёма AGP
- импорт kotlinx.coroutines.launch воткнут посреди androidx-блока: исправлено, перенесён после проектных импортов
