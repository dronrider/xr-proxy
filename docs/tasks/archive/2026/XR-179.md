# XR-179: Поезд выката: merge без деплоя копит пачку мелочи, один билд и одна проверка на всех (правки devkit: shipctl merge --train и ship, инвариант и критерии пачки в RULES.board), дизайн в LLD-31

Дизайн в [LLD-31](../lld/31-release-train.md). Сама правка живёт в репозитории devkit, здесь только трекинг: боль и обкатка в xr-proxy.

## Ход работы

- Реализовано по LLD, вариант (а) с тегом: `shipctl merge --train` сливает без выката (задача остаётся в In progress), `shipctl ship` одним деплоем везёт поезд и разом переводит его в Check, состав вычисляется из git по окну `deployed..main`. Одиночный merge при непустом поезде отбивается, откат задачи из невыкаченного поезда не запускает деплой.
- Сверх LLD по итогам ревью: тег двигает каждая точка выката (ship, одиночный merge, revert с повторным выкатом), защита от осиротевших задач (код в окне есть, строка ушла из In progress: merge и ship отказывают, status показывает аномалию), общая граница отката с конвенцией «ID плюс слово откат» для кастомного -m.
- Ревью три круга, замечания ниже; 14-е отклонено как нештатный сценарий, предел зафиксирован в README shipctl.
- Коммиты в devkit: f291e99, 4dbd46b (правила), b074660, 33446b3, e277ff9. Пуш devkit за пользователем.

## Ревью

- тег deployed не пушится при merge --train, на второй машине поезд невидим и одиночный merge увозит чужие правки: исправлено
- ship пушит тег до его сдвига, при падении пуша доски origin остаётся со старым тегом: исправлено
- ship без --push и автономии молчит, что сдвинутый тег надо пушить руками (-f): исправлено
- inTrain в revert проглатывает ошибки board/trainTasks, fail-open на аварийном пути: исправлено
- откат с кастомным -m не распознаётся, откаченная задача числится в поезде и уедет в Check: исправлено
- задача, выведенная руками из In progress, тихо выпадает из поезда, код едет на прод без Check: исправлено
- поездной путь не тестируется с origin, пуш тега ничем не покрыт: исправлено
- ошибка пересчёта состава в хвосте merge --train хоронит отчёт об уже прошедшем слиянии: исправлено
- revert осиротевшей задачи катил повторный выкат и увозил чужой поезд на прод: исправлено
- провал пуша тега в ship ронял команду и бросал доску непереведённой: исправлено
- откат ловился подстрокой, фичекоммит со словом откатить выкидывал задачу из поезда; граница taskCommits не знала кастомный -m: исправлено
- мягкий провал пуша тега в ship не был покрыт тестом: исправлено
- защита revert была завязана на текстовый формат списка осиротевших: исправлено
- задача, закрытая в архив мимо ship, невидима для состава поезда: отклонено, закрытие поездной задачи мимо ship не штатная операция, предел зафиксирован в README shipctl: закрывать только из Check после ship
