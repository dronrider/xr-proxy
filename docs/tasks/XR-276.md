# XR-276: Выпуск setup-токена с готовой командой установки в админке хаба

записана 2026-08-10

## Чего хотим

Setup-токен (XR-127, регистрация плюс инвайт одной строкой) сегодня
выпускается только через API: `POST /shares/setup-token` есть в
`xr-hub/src/api/mod.rs:110`, а в админ-UI люка нет вовсе. Сценарий «выдать
человеку файлообмен под ключ» заканчивается ручным curl с админ-сессией.

Хотим кнопку в админке по образцу уже стоящего модала reg-токена (вкладка
Shares, «Команда установки агента», `SharesList.vue`, `openInstall` и
`generateInstall`): выпуск setup-токена и готовая команда установки с
подставленным токеном для Linux/macOS (`install.sh --setup ...`) и Windows
(`install.ps1` с `XR_SETUP`), с кнопкой копирования. Раз внутри инвайт,
модалу нужны его параметры: какой инвайт прикрепить или завести новый
(`create_setup_token` в `xr-hub/src/api/register.rs` это уже умеет, смотреть
поля запроса).

Место кнопке выбрать по смыслу: рядом с существующей на Shares или на
вкладке инвайтов, где живёт то, к чему setup-токен привязывает шару.

## Ранг

`0+3+1+0+0 = 4`, P3.

- Серьёзность 0 (Minor). Удобство: обход дешёвый и очевидный, reg-токен
  модалом плюс команда шары руками, либо готовый API.
- Ценность 3. Небольшое удобство нечастого сценария «выдать под ключ».
- Неопределённость 1. Образец-модал и API готовы, осталось сделать; единственная
  развилка это форма выбора инвайта.
- Поправка на баг 0. Новая работа.
- Рычаг 0. Ничего не разблокирует.

## Сценарий проверки

Агентский. Поднять хаб на синтетическом окружении, открыть админку headless
браузером или дёрнуть те же ручки, что зовёт модал: выпуск setup-токена
отвечает токеном, собранная UI команда содержит его и адрес хаба; выпущенным
токеном проходит регистрация фикстурного агента (или, без полного стенда,
токен валиден по ответу ручки регистрации). Копирование в буфер проверяется
наличием кнопки и текстом команды, сам буфер headless не нужен.
