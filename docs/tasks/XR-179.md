# XR-179: Поезд выката: merge без деплоя копит пачку мелочи, один билд и одна проверка на всех (правки devkit: shipctl merge --train и ship, инвариант и критерии пачки в RULES.board), дизайн в LLD-31

## Ревью

- тег deployed не пушится при merge --train, на второй машине поезд невидим и одиночный merge увозит чужие правки
- ship пушит тег до его сдвига, при падении пуша доски origin остаётся со старым тегом
- ship без --push и автономии молчит, что сдвинутый тег надо пушить руками (-f)
- inTrain в revert проглатывает ошибки board/trainTasks, fail-open на аварийном пути
- откат с кастомным -m не распознаётся, откаченная задача числится в поезде и уедет в Check
- задача, выведенная руками из In progress, тихо выпадает из поезда, код едет на прод без Check
- поездной путь не тестируется с origin, пуш тега ничем не покрыт
- ошибка пересчёта состава в хвосте merge --train хоронит отчёт об уже прошедшем слиянии
- revert осиротевшей задачи катил повторный выкат и увозил чужой поезд на прод
- провал пуша тега в ship ронял команду и бросал доску непереведённой
- откат ловился подстрокой, фичекоммит со словом откатить выкидывал задачу из поезда; граница taskCommits не знала кастомный -m
