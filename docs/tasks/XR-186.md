# XR-186: Иконка щита разошлась с LLD-06: серо-стальной глянец вместо брендового cyan, плюс круглая плашка спорит с кольцом свечения. Перерисовать иконку и сделать осмысленную анимацию вокруг щита

## Ревью

- Цикл радара 2400 мс не применялся: InfiniteTransition читает animationSpec только при заведении состояния, менялся лишь spec. Первая композиция всегда Idle, значит радар шёл со скоростью сходящихся колец: исправлено
- Приглушение ломало вырез молнии: alpha висела на каждом пути, полупрозрачный фон поверх полупрозрачного щита давал не дырку, а цветное пятно. Бьёт по Idle, то есть по самому частому состоянию: исправлено
- Щит растягивался: масштаб по осям считался раздельно, на квадратном холсте пропорция 100 на 120 расплывалась в ширину: исправлено
- Кольца стояли слипшимися в начале: StartOffset по умолчанию это задержка, а не перемотка, поэтому при входе на поднятый туннель все три висели на старте: исправлено
- Кольца вылезали за пределы иконки на строку статуса: Canvas не обрезает рисование, дальняя граница 1.55 давала вылет за 16dp отступа: исправлено
- LLD-06 описывал молнию с выступающими за щит концами и перечислял несуществующую фазу Error: исправлено
- Мелочи: дальние границы радара и схождения не совпадали (1.55 против 1.5), мёртвый coerceAtLeast, аллокация путей на каждый кадр: исправлено, границы свели в общие константы, мёртвый coerce убран; аллокацию путей оставил, два мелких Path на кадр на фоне работы Compose незаметны
