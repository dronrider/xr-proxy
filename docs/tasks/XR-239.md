# XR-239: Хаб отдаёт админку и остальные ответы без защитных заголовков: ни CSP, ни X-Content-Type-Options, ни Referrer-Policy (найдено попутно с XR-192, там закрыта только страница инвайта)

## Что происходит

XR-192 закрыл защитными заголовками только страницу инвайта. Админка
и остальные ответы хаба уходят без CSP, X-Content-Type-Options
и Referrer-Policy.

## Чего хотим

Защитные заголовки стоят на всех ответах хаба, включая статику админки,
одной точкой, а не по одному хендлеру. Задача из состава цели XR-286,
конвейер идёт по её файлу.

## DoD

- Ответы хаба несут CSP, X-Content-Type-Options и Referrer-Policy, включая
  статику admin UI; страница инвайта не теряет свои заголовки из XR-192.
- Наличие заголовков покрыто тестом стенда xr-hub.
- Сквозная проверка после выката: `curl -sI https://$HUB/` содержит строку
  `Content-Security-Policy`.
