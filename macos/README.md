# XR Proxy для macOS

Весь IP-трафик Mac уходит в туннель на сервер. Приложение перехватывает
трафик средствами Network Extension, резолв доменов идёт через туннель,
падение туннеля не открывает прямой выход.

## Первый запуск

1. Установи зависимости. Нужны Xcode (полный, не Command Line Tools),
   Rust (`rustup`), `xcodegen` (`brew install xcodegen`).

2. Собери приложение.

   ```sh
   macos/scripts/build-macos.sh
   ```

   Скрипт соберёт staticlib ядра, прогонит юниты чистой логики и
   сгенерирует Xcode-проект. Без флага `--sign` получится debug-сборка
   для локальной проверки.

3. Скопируй `.app` из каталога сборки в `/Applications` и запусти.

4. Настрой подключение. Приложение откроет окно с кнопкой
   «Подключить». Конфиг (адрес сервера и ключ) кладётся в App Group,
   его читает процесс расширения.

5. Подтверди расширение. macOS спросит разрешение на добавление
   VPN-конфигурации. Открой Системные настройки, раздел «Сеть» и
   «VPN и фильтры».

6. Нажми «Подключить». Статус изменится на «Подключено», весь трафик
   пойдёт через туннель.

## Проверка, что трафик идёт через туннель

```sh
curl -4 https://ifconfig.me
```

Адрес должен совпадать с адресом сервера. Открой любой заблокированный
сайт. Он должен открыться через туннель. Проверь DNS:

```sh
scutil --dns | grep nameserver
```

Должен стоять адрес FakeDns внутри туннеля.

## Если туннель не поднимается

Приложение пишет ошибку в окно. Частые причины: неверный адрес сервера,
неверный ключ, сервер недоступен с текущей сети. Проверь конфиг и
доступность сервера.

## Для разработчиков

Каталог `macos/XrCore` держит SwiftPM-пакет чистой логики. Юниты
гоняются `swift run xrcore-tests` из этого каталога, Xcode не нужен.

Каталог `macos/XrMac` держит исходники Xcode-проекта. Файл `project.yml`
описывает таргеты, `xcodegen generate` собирает `.xcodeproj`.

Каталог `xr-ios-ffi` держит C FFI-мост к ядру. Тесты гоняются
`cargo test -p xr-ios-ffi`.

Подпись и нотаризация описаны в [SIGNING.md](SIGNING.md). Архитектура
перехвата лежит в [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md),
раздел 4.11.

## Сборка и тесты

```sh
# Rust: весь workspace
cargo test --workspace

# Rust: только мост
cargo test -p xr-ios-ffi

# Swift: чистая логика
cd macos/XrCore && swift run xrcore-tests

# Полная сборка приложения
macos/scripts/build-macos.sh
```

## Вопросы и ответы

**Работает ли приложение без подписи?** На той машине, где собрано.
Для чужих машин нужна подпись и нотаризация (SIGNING.md).

**Что будет при падении туннеля?** Соединения рвутся, прямой выход не
открывается. Kill-switch включён (`includeAllNetworks`). Приложение
всегда работает в туннеле или остаётся без сети.

**Можно ли выбирать приложения для проксирования?** Нет, весь
IP-трафик уходит в туннель целиком. Раздельный туннель по приложениям
это отдельная задача (XR-016).

**Какой DNS используется?** FakeDns внутри туннеля. Провайдерский
резолвер не используется, DoT блокируется. Системный DoH остаётся
границей первой версии.
